İki İşaretçi (Two Pointers) Tekniği

Ekstra bellek tahsis etmeden ($O(1)$ Space), metin üzerinde iki uçtan merkeze doğru ilerleyerek palindrom doğrulama.

❌ Kaba Kuvvet (Reversal) O(N) Alan / Ek Bellek

Önce tüm metni filtreleyip yeni bir diziye kopyalar, ardından tersini alıp karşılaştırır:

clean = [c.lower() for c in s if c.isalnum()]
return clean == clean[::-1]

⚠️ 100 MB'lık bir metinde fazladan 200 MB RAM tüketir ve büyük veri işlem hatlarında bellek patlamasına yol açar.

✅ Two Pointers (İki İşaretçi) O(1) Alan / Sabit Bellek

Metni kopyalamaz; sol (left) ve sağ (right) işaretçilerle doğrudan orijinal metinde gezinir:

while left < right:
  s[left].lower() == s[right].lower()

🚀 Yalnızca iki tamsayı işaretçi değişkeni tutulur. Metin ne kadar devasa olursa olsun ek bellek tüketimi 0'dır!

🎮 İnteraktif Two Pointers Adım Adım Simülatörü

Aşağıdaki örneklerden birini seçin ve "Sonraki Adım" butonuna basarak iki işaretçinin noktalama işaretlerini nasıl atladığını ve karakterleri nasıl eşleştirdiğini canlı izleyin:

Adım: 0 / 0
Simülasyon hazır. "Sonraki Adım" butonuna basarak taramayı başlatın.

def is_palindrome(s: str) -> bool:
    """
    LeetCode #125: Valid Palindrome (Geçerli Palindrom Kontrolü)

    Algoritma Tekniği: İki İşaretçi (Two Pointers)
    Zaman Karmaşıklığı: O(N) - Metin tek sefer taranır.
    Alan Karmaşıklığı: O(1) - Ek liste tahsis edilmez, sabit bellek kullanılır.
    """
    left = 0
    right = len(s) - 1

    while left < right:
        # Sol işaretçiyi alfasayısal olmayan karakterleri atlayarak ilerlet
        while left < right and not s[left].isalnum():
            left += 1

        # Sağ işaretçiyi alfasayısal olmayan karakterleri atlayarak gerilet
        while left < right and not s[right].isalnum():
            right -= 1

        # Karakterleri küçük harfe çevirerek karşılaştır
        if s[left].lower() != s[right].lower():
            return False

        left += 1
        right -= 1

    return True

📊 Karmaşıklık & Performans Analizi

Metrik Değer Açıklama & Neden
Zaman (Time) O(N) left ve right işaretçileri birbirine doğru yaklaşır; her karakter en fazla bir kez okunur.
Alan (Auxiliary Space) O(1) Yalnızca iki sayı değişkeni (left, right) kullanılır. $O(N)$ string klonlama yapılmaz.
Edge Cases 100% Kapsama Boş string "", tek boşluk " ", yalnızca noktalama ".,?!", tek karakter "a" durumları başarıyla ele alınır.

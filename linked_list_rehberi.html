Singly Linked List & In-Place Reversal

Düğümlerin işaretçilerini bellekte kopyalamadan ($O(1)$ Space), üç işaretçi iterasyonuyla tersine çevirme sanatı.

📦 Neden Bağlı Liste (Linked List)?

Diziler (Array) bellekte ardışık bloklar talep ederken; bağlı liste her düğümü bağımsız olarak RAM'in herhangi bir yerine yerleştirir ve next işaretçisi ile bağlar. Başa ekleme (prepend) dizilerde $O(N)$ iken bağlı listede $O(1)$'dir.

🔄 Üç İşaretçi Tekniği (Three Pointers)

Bir bağlı listeyi tersine çevirirken kopya oluşturmak yerine prev, curr ve next_node olmak üzere üç değişken tutulur. Her adımda işaretçinin yönü ters çevrilir. Ekstra alan: $O(1)$.

🎮 İnteraktif İşaretçi Yönlendirme Simülatörü

"Sonraki Adım" butonuna basarak prev, curr ve next_node işaretçilerinin nasıl hareket ettiğini ve okların nasıl yön değiştirdiğini izleyin:

Adım: 0 / 0
Simülasyon hazır. "Sonraki Adım" butonuna basarak ters çevirme sürecini başlatın.

🐍 Python Çözümü: algorithms/reverse_linked_list.py

def reverse_linked_list(head: Optional[ListNode[T]]) -> Optional[ListNode[T]]:
    prev: Optional[ListNode[T]] = None
    curr: Optional[ListNode[T]] = head

    while curr is not None:
        next_node = curr.next  # 1. Gelecek düğümü sakla
        curr.next = prev       # 2. İşaretçiyi geriye çevir
        prev = curr            # 3. prev'i bir adım ilerlet
        curr = next_node       # 4. curr'ı bir adım ilerlet

    return prev  # Yeni baş düğüm (Head)

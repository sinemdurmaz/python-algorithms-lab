Merge Two Sorted Lists & Dummy Head

İki sıralı bağlı listeyi sahte baş düğüm (Dummy Head) tekniğiyle $O(1)$ ek bellekte fermuar gibi birleştirme.

🛡️ Dummy Head (Sahte Baş) Deseni

Birleştirilen yeni listenin başı hangisi olacak? (list1 mi yoksa list2 mi?) sorusunu ortadan kaldırmak için geçici bir dummy = ListNode(None) oluşturulur. Listenin kuyruğu (tail) bu sahte başa bağlanır. Fonksiyon sonunda dummy.next dönülür.

⚡ O(1) Bellek ile In-Place Splice

Yeni düğüm nesneleri (ListNode) allocate edilmez! Bunun yerine mevcut düğümlerin next işaretçileri küçük olana doğru yeniden yönlendirilir. Bellek karmaşıklığı $O(1)$'dir.

def merge_two_sorted_lists(list1: Optional[ListNode[T]], list2: Optional[ListNode[T]]) -> Optional[ListNode[T]]:
    dummy = ListNode(None)
    tail = dummy

    while list1 is not None and list2 is not None:
        if list1.val <= list2.val:
            tail.next = list1
            list1 = list1.next
        else:
            tail.next = list2
            list2 = list2.next
        tail = tail.next

    tail.next = list1 if list1 is not None else list2
    return dummy.next

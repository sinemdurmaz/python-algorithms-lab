Kaplumbağa (1 adım) ve Tavşan (2 adım) işaretçileriyle döngülü bağlı listelerde sonsuz döngüye düşmeden $O(1)$ bellekle tespit.

Adım: 0 / 0
Simülasyon hazır. "Sonraki Adım" butonuna basarak yarışı başlatın.

🐍 Python Çözümü: algorithms/has_cycle.py

def has_cycle(head: Optional[ListNode[T]]) -> bool:
    if head is None or head.next is None:
        return False

    slow = head  # 1 adım (Kaplumbağa)
    fast = head  # 2 adım (Tavşan)

    while fast is not None and fast.next is not None:
        slow = slow.next
        fast = fast.next.next

        if slow is fast:
            return True  # Döngü bulundu!

    return False  # fast None'a ulaştı -> Döngü yok

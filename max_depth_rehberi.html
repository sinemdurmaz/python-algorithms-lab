Maximum Depth of Binary Tree

Özyinelemeli (DFS) mantıkla kökten en uzak yaprak düğüme kadar olan derinliği $O(N)$ zamanda hesaplama.

🌳 Derinlik (Depth) Formülü

Bir düğümün derinliği: 1 + max(sol_dal_derinliği, sağ_dal_derinliği) formülüyle hesaplanır. Düğüm boş (None) ise derinlik 0'dır.

⚡ Karmaşıklık Analizi

Ağaçtaki her düğüm tam bir kez ziyaret edildiği için Zaman: $O(N)$; çağrı yığınında tutulan en yüksek çağrı sayısı ağaç yüksekliği kadar olduğundan Alan: $O(H)$'dir.

🎮 Canlı Ağaç Derinlik Simülatörü

Örnek Ağaç: [3, 9, 20, null, null, 15, 7]. Adım adım DFS taramasını izleyin:

🐍 Python Çözümü: algorithms/max_depth_binary_tree.py

def max_depth(root: Optional[TreeNode[T]]) -> int:
    if root is None:
        return 0

    left_depth = max_depth(root.left)
    right_depth = max_depth(root.right)

    return 1 + max(left_depth, right_depth)

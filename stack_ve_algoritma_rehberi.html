LIFO Prensibi (Last In, First Out)

Üst üste dizilmiş yemek tabakları gibidir. 3. tabağı almadan 1. tabağa dokunamazsınız!

  • push(x): En üste yeni tabak koyar.
  • pop(): En üstteki tabağı alır.
  • peek(): En üsttekine sadece göz atar.
Operasyon Zaman Karmaşıklığı (Time Complexity) Açıklama
push(x) O(1) Listenin sonuna ekleme anında yapılır.
pop() O(1) Listenin sonundaki eleman anında çıkarılır.
peek() O(1) Son elemana indeksle erişim O(1)'dir.

🧩 2. Algoritma: Dengeli Parantezler (LeetCode #20)

Verilen "{ [ ( ) ] }" dizisinin geçerli olup olmadığını Stack ile nasıl anlarız? 

Girdi: "{ [ ( ) ] }"

1. Karakter '{': Açılış parantezi -> Stack'e at.        Stack: ['{']
2. Karakter '[': Açılış parantezi -> Stack'e at.        Stack: ['{', '[']
3. Karakter '(': Açılış parantezi -> Stack'e at.        Stack: ['{', '[', '(']
4. Karakter ')': Kapanış! Stack'ten çıkar: '(' ile eşleşti! Stack: ['{', '[']
5. Karakter ']': Kapanış! Stack'ten çıkar: '[' ile eşleşti! Stack: ['{']
6. Karakter '}': Kapanış! Stack'ten çıkar: '{' ile eşleşti! Stack: []

Sonuç: Yığın bomboş kaldı -> Tüm parantezler DENGELİDİR (True)! ✅

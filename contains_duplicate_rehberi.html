Contains Duplicate II: Mesafe Kontrolü

Kayan pencere (Sliding Window) ve Hash Set güçlerini birleştirerek $O(N)$ zaman ve $O(k)$ alanda yakın eleman tekrarını yakalama.

🔍 Problem Nedir?

Bir dizide aynı değere sahip iki elemanın indeks farkının en fazla $k$ olup olmadığını bulmak (nums[i] == nums[j] ve abs(i - j) ≤ k).

🛡️ Dinamik Hash Set Penceresi

Kümede yalnızca son $k$ eleman tutulur. Boyut $k$'yı aştığında pencereden çıkan en eski eleman window.remove(nums[i - k]) ile temizlenir. Alan: $O(k)$.

🎮 Canlı Simülatör: nums = [1, 2, 3, 1], k = 3

Hash Set Penceresi (Maks {k}):
Adım: 0 / 3
Simülasyon hazır. "Sonraki Adım" butonuna basarak taramayı başlatın.

🐍 Python Çözümü: algorithms/contains_duplicate.py

def contains_nearby_duplicate(nums: list[int], k: int) -> bool:
    window: set[int] = set()

    for i, num in enumerate(nums):
        if num in window:
            return True  # k mesafesi içinde tekrar bulundu!

        window.add(num)

        if len(window) > k:
            window.remove(nums[i - k])  # En eskiyi çıkar

    return False
